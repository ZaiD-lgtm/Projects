I successfully pretrained a language model based on the GPT architecture from scratch, comprising approximately 700 million parameters. The model was trained on the FineWeb dataset with a total of 10 billion tokens.
Architecture: vocab_size = 50257, word embedding dimension = 1456, number of layers = 20, number of heads = 16. max sequence length = 4098. Due to the constraints of GPU, I implemented several optimization strategies for memory and VRAM management, including mixed-precision training and a custom data loader.The pretraining process gave me a deep, hands-on understanding of core AI concepts and large-scale model training. I am now exploring advanced topics such as knowledge distillation, LLM watermarking, and various fine-tuning methods to further enhance the model’s performance.
This project not only serves as an excellent learning experience but also demonstrates my strong interest, technical capability, and growing expertise in the field of artificial intelligence.
The training version_1 code is heavy in terms of computation and memory usage compared to version_2 which includes mixed floating point precision, gradient accumulation, custom dataloader, etc. as it helped a lot to train on limited resources, keeping the parameters as it is!
